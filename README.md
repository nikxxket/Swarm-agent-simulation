# Децентрализованное управление роем агентов

Данный проект представляет собой визуальную симуляцию децентрализованного управления роем малоразмерных агентов на языке Java. Агенты используют алгоритм роя частиц (Particle Swarm Optimization, PSO) для поиска оптимального пути к цели, обхода препятствий и доставки уникальных деталей в точку сборки.

## Описание
**Децентрализованное управление:** Каждый агент принимает решения автономно, без центрального управляющего узла.
**Алгоритм PSO:** Движение агентов основано на инерциальной, когнитивной (личный опыт) и социальной (опыт лучшего соседа) составляющих.
**Обход препятствий:** Агенты умеют находить пути вокруг статических препятствий на сетке.
**Предотвращение коллизий:** Встроенная система разрешения конфликтов не позволяет агентам занимать одну и ту же клетку.
**Плавная анимация:** Благодаря интерполяции визуальных координат, движение роя выглядит плавным, несмотря на дискретную сетку.

## 🛠 Технологический стек
**Язык:** Java (JDK 8+)
**GUI:** Java Swing / AWT
**Архитектура:** ООП, многопоточность

## 📂 Структура проекта
`Agent.java` — описывает состояние агента (координаты, вектор скорости) и содержит математику расчета нового вектора по формуле PSO.
`Simulation.java` — основной класс среды. Управляет сеткой, препятствиями, запускает цикл симуляции и обрабатывает коллизии. Содержит метод `main` для запуска.
`SimulationPanel.java` — панель отрисовки (наследник `JPanel`). Отвечает за визуализацию сетки, препятствий и плавное перемещение агентов.
`Obstacle.java` — вспомогательный класс для хранения координат и габаритов препятствий.
